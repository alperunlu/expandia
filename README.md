# Expandia - Godot Strateji Oyunu

## Kurulum

1. Bu projeyi indir.
2. Godot ile `project.godot` dosyasını aç.
3. Çalıştırmak için F5'e bas.

## Klasör Yapısı

- `src/` : Tüm ana sahneler ve scriptler
- `assets/` : Görseller, fontlar, sesler
- `main.tscn` : Oyun ana sahnesi
- `project.godot` : Godot proje dosyası
